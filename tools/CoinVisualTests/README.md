# CoinVisualTests

`CoinVisualTests` is a small scene-level visual regression runner for Coin's
LegacyGL reference renderer and DrawList parity path. It creates a hidden
desktop OpenGL context, renders `.iv` scenes, and compares captured PNGs with
checked-in LegacyGL baselines.

LegacyGL remains the sole baseline authority. DrawList visual output is an
additional comparison path.

## Commands

```text
CoinVisualTests snapshot [spec-id|scene.iv] [options]
CoinVisualTests compare --expected image.png --actual image.png --diff diff.png --metrics metrics.json
CoinVisualTests run [options]
CoinVisualTests update [options]
```

Rendering commands accept `--renderer legacy|drawlist` and
`--gl-profile compat|core`. The defaults are `legacy` and `compat`.

`legacy` uses `SoGLRenderAction` and requires a compatibility profile.
`drawlist` traverses through `SoIRRenderAction`, `SoDrawList`, and
`SoGLRenderBackend`, and supports both compatibility and core profiles.

`baseline:` remains the default and is normally authored by LegacyGL. A spec
may provide renderer-specific overrides when execution semantics differ:

```yaml
baseline: ../baselines/gl/transparency_order_basic.png
baselines:
  drawlist: ../baselines/gl/drawlist/transparency_order_basic.png
```

DrawList comparisons use the override when present and otherwise fall back to
`baseline:`. DrawList baseline updates require an explicit renderer-qualified
path, so a broad update cannot overwrite LegacyGL references accidentally.
Actual artifacts are separated under `gl/legacy/`, `gl/drawlist-compat/`, and
`gl/drawlist-core/`.

`run` discovers `.yml` files in the configured source-tree spec directory. The
default directory and build artifact root are generated by CMake. Use
`--spec-dir` or `--artifacts-dir` to override them.

## Specs

YAML is a thin execution manifest. The only required fields are `id`, `scene`,
and either `baseline` or `baselines`:

```yaml
id: cube_basic
scene: ../scenes/cube.iv
baseline: ../baselines/gl/cube_basic.png
```

The default viewport is 512x512 with a neutral background. Override only the
parts that matter for a fixture:

```yaml
viewport:
  background: [0.05, 0.08, 0.12, 1.0]
```

An optional camera override, viewport override, and comparison policy
(`default`, `strict`, `exact`, or `relaxed`) may be added. Rendering state
belongs in the `.iv` scene rather than in YAML.

Perspective camera overrides use `fov_deg`; orthographic camera overrides use
`height`. These fields are intentionally distinct because they have different
units.

## Baselines and CI

Run `CoinVisualTests update` deliberately when authoring or accepting new
baselines. A failed snapshot or baseline copy is a failed update. CI runs the
suite in the Ubuntu LegacyGL-enabled job and uploads actual images, diffs,
metrics, and CTest results under the single `render_artifacts` root; render
outputs live in its `gl/` subdirectory.

The CMake option is:

```text
COIN_BUILD_VISUAL_TESTS=ON
```

## Build-system requirement

The project requires CMake 3.21 or newer because the GLSL root-shader
embedding pipeline uses build-time dependency/depfile support. This is a
build-system requirement; DrawList rendering itself does not depend on CMake.

CoinVisualTests can be built with or without LegacyGL. A build without
LegacyGL can still run DrawList comparisons against committed reference images
and update explicitly configured DrawList baselines.
